# GTA VI — Vice Beach (browser demo)

Single-file Three.js game in `index.html`. No build step.

- Serve with `python3 -m http.server 8642` (ES modules + CDN importmap require http, `file://` is blocked).
- Debug/test hook: `window.__G` exposes player, cars, peds, mission, shoot, hurtPlayer, addCrime, setTime.
- The user plays in the same Playwright-controlled browser window used for testing —
  never inject keyboard input or teleport entities while they may be playing.
- Use a cache-busting query (`?v=...`) when reloading; same-URL goto can be a no-op.

## Smoke test

Serve the repo with `python3 -m http.server 8642`, then load `http://127.0.0.1:8642/index.html?v=<timestamp>`. Click the start screen, confirm the canvas renders nonblank with no page or console errors, and test both desktop and mobile-sized viewports.
